# 随机 API 密钥轮换

## 摘要

将 `rotateApiKey` 从顺序轮换更改为随机选择，避免连续重复。

## 当前行为

- 使用从 0 开始的 `currentIndex`
- 始终按顺序返回密钥：key1 → key2 → key3 → key1...

## 新行为

- 每次调用从列表中随机选择一个密钥
- 避免连续两次选择相同的密钥（当存在 2+ 个密钥时）
- 单个密钥或空字符串：保持不变

## 实现

1. 将 `currentIndex` 替换为 `lastSelectedIndex`（初始值为 -1 或 null）
2. 使用 `Math.random()` 生成随机索引
3. 如果随机索引等于上一个且 keys.length > 1，则重新随机
4. 存储选定的索引以供下次调用比较

## 测试更改

- 删除断言特定序列顺序的测试
- 添加验证以下内容的测试：
  - 密钥来自有效集合
  - 无连续重复（运行多次迭代）
  - 单个密钥仍然有效
  - 边界情况（空值、空白）仍然有效
