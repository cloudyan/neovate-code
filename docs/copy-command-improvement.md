# /copy 命令改进说明

## 改进内容

原来的 `/copy` 命令只能复制最后一条 AI 响应，现在已经改进为类似 `/fork` 的交互式选择界面。

## 新功能特性

1. **交互式选择界面**: 执行 `/copy` 后会显示一个包含所有 AI 响应的列表
2. **上下导航**: 使用 ↑/↓ 键在响应列表中导航
3. **预览功能**: 每个响应显示时间戳和内容预览（前80个字符）
4. **一键复制**: 选中后按 Enter 键即可复制到剪贴板
5. **状态反馈**: 显示复制状态（成功/失败/进行中）
6. **中文界面**: 所有提示信息都使用中文

## 使用方法

1. 在 Neovate Code 中输入 `/copy`
2. 使用 ↑/↓ 键选择要复制的 AI 响应
3. 按 Enter 键复制选中的响应
4. 按 Esc 键取消操作

## 技术实现

- 新增 `CopyModal` 组件（参考 `ForkModal` 设计）
- 在 store 中添加 `copyModalVisible` 状态和相关 actions
- 修改 `/copy` 命令实现，从直接复制改为显示选择界面
- 在 `App.tsx` 中集成 `CopyModal` 组件

## 优势

- **更好的用户体验**: 不再局限于只能复制最后一条响应
- **提高效率**: 快速找到并复制需要的历史响应
- **直观操作**: 可视化界面比记忆命令更友好
- **一致性**: 与 `/fork` 命令保持一致的交互模式
- **无干扰操作**: 执行命令不会添加新的消息到对话历史中

## 修复说明

**问题**: 初始版本中 `/copy` 命令执行选择后会触发一次新的问话。

**原因**: 在命令实现中调用了 `onDone('')`，导致系统将空字符串作为新的用户消息处理。

**解决方案**: 修改为调用 `onDone(null)`，表示命令执行完成但不添加任何消息到历史记录中。
